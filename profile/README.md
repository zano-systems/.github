We are Zephyr® contributors and maintainers. We work upstream, and we ship to
production: firmware, board bring-up and the hardware it runs on.

## Open source

Everything below is built and maintained by Zano engineers.

| Project | What it does |
| --- | --- |
| [**ZBus**](https://docs.zephyrproject.org/latest/services/zbus/index.html) | The lightweight publish-subscribe message bus in Zephyr®, upstream. |
| [**Objective-Z**](https://github.com/zano-systems/objective-z) | An ahead-of-time subset of Objective-C, transpiled to plain C for Zephyr®. No runtime, no heap. |
| [**Zephlet**](https://github.com/rodrigopex/zephlet) | Domain-isolated components that talk over ZBus through commands and events. |
| [**ZView**](https://docs.zephyrproject.org/latest/develop/manifest/external/zview.html) | A host-side visualizer for live thread, stack, CPU and heap statistics, read over SWD. |
| [**Lua Zephyr**](https://github.com/zano-systems/lua_zephyr) | Lua 5.5 on Zephyr®, with isolated heaps and ZBus access. |

### Experiments

| Project | What it explores |
| --- | --- |
| [**ZView GUI**](https://github.com/zano-systems/zview-gui) | A browser frontend for ZView, built with GPUI Kit and WebAssembly. |
| [**zbus-dbus-bridge**](https://github.com/zano-systems/zbus-dbus-bridge) | Connects Zephyr® (ZBus) and Linux (D-Bus) on an AMP MPU. |

## What we do

- **Architecture & product firmware:** system architecture, BLE/LoRa/Wi-Fi, low power, MCUboot and OTA, device management.
- **Board enablement & drivers:** bring-up, Devicetree, custom drivers, upstream support.
- **Testing & optimization:** HIL test benches, power profiling, tracing, CI automation.
- **Custom electronic design:** schematics, multilayer PCB layout, prototype validation, DFM/DFT.
